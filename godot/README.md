# Godot native Shire migration

This folder is a **native Godot 4 3D project**, not a larger HTML file.
Import `godot/project.godot` into Godot Engine (target 4.7.2 Standard).

Controls: WASD walk; Shift run; mouse look; V first/third person; E interact; F5 save; Esc mouse release.
First vertical slice includes terrain, Bag End exterior/interior, animated time-of-day, fog/rain response, batched trees, six basic NPC routines, persistent dialogue topics and save file.
**Status:** source is committed; real Godot runtime and Windows hardware FPS remain untested. The larger independent local ZIP checkpoint produced in the same session contains additional Hobbiton scripts and a first-party authored GLB cart model; this GitHub directory is the minimal native bootstrap, not an identical copy of that ZIP.
No commercial film/book assets or material from fellowship-personal-game are used.

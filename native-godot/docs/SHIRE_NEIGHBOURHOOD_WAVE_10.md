# Shire Wave 10: authored outdoor life

Adds gameplay world content, not a new roadmap or a visual quality certification.

- Nine separate original themed exterior workshops, one beside each enterable home. Each contains a bench, footstones, six flowering tubs, handcrafted work items, and a signboard that marks one new journal interaction.
- Nine additional bilingual walk-up discoveries; these use the existing one-time field-note, save and restore systems. Together with the earlier twelve environmental notes there are now 21.
- Fifteen batched countryside craftwork sets with deterministic placements: stone walls, hay, six flower meadows, vegetable plots, beehives, signposts, rest benches and field hedges. These are GPU instanced MultiMeshes, with no physics simulation on the individual props.
- Twenty-four original mesh butterflies with lightweight flight and weather/daylight visibility rules, without imported imagery.
- All introduced geometry is code-authored and original. Existing licensed Poly Haven / CC0 pipelines are unchanged.
- Nine-house household smoke keeps all 27 interior bilingual interactions and reward/save regressions. It now verifies outdoor prop presence and fixes a RefCounted object incorrectly declared as Node.
- This work has not been judged final or photorealistic in a visual Godot playthrough. Requires engine validation, camera screenshots, performance measurement, and an actual Windows run before release.

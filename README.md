## Design contract

- Browser 3D; optional Windows EXE later.
- First/third person; hero changes by chapter.
- Semi-open explorable regions, cinematic story.
- English voices, Arabic subtitles, on-screen Fallout-style choices; no microphone.
- NPC world awareness, authored memory and daily routines. **Generative AI NPCs not implemented.**
- Optimize for Intel i7 gen 6 / 8 GB RAM / about 2 GB VRAM.
- Film visual fidelity is the aspiration, **not** the current art quality. The models remain simplified and need replacement with high-quality licensed/self-authored assets.
- Canon outcomes should remain consistent; original side quests and dialogue must be clearly distinguished.

## Important publishing boundary
